# AI Interview Coach

This module provides comprehensive prompts for using Large Language Models (LLMs) as your personal interview coach. 

While specific prompts for individual topics (like Python, React, or specific System Design questions) are included in their respective sections, this directory focuses on **full interview simulations, roleplay setups, behavioral evaluation rubrics, and technical mock loops**.

## Choose Your AI Coach

Different LLMs excel at different aspects of interview coaching:

*   **[ChatGPT](chatgpt-prompts.md):** Excellent for conversational flow, behavioral mock interviews, and step-by-step technical problem solving.
*   **[Claude](claude-prompts.md):** Superior context window makes it ideal for evaluating large codebases, deep system design reviews, and nuanced feedback on long behavioral stories (STAR method).
*   **[Gemini](gemini-prompts.md):** Great for up-to-date information, reviewing recent tech trends, and rapid-fire technical trivia.

## How to Use These Prompts

1.  **Set the Stage:** Start with a "System Prompt" or "Roleplay Setup" to give the AI its persona.
2.  **Define the Rules:** Clearly state how you want the interview to proceed (e.g., "Ask one question at a time," "Wait for my response before evaluating").
3.  **Provide the Rubric:** Give the AI the criteria by which you want to be evaluated.
4.  **Simulate and Iterate:** Treat the interaction like a real interview. Don't break character!
