# Engineering Glossary

> A searchable A–Z index of common engineering and interview terms. 
> Terms link to their respective deep-dive chapters in the Handbook.

## A
- **A/B Testing**: A randomized experiment comparing two variants (A and B) to determine which performs better. [See Data Science →](./22-data-science/statistics.md)
- **ACID**: Atomicity, Consistency, Isolation, Durability. The core properties that guarantee database transactions are processed reliably. [See Databases →](./11-databases/fundamentals.md)
- **Agile**: An iterative approach to software development and project management. [See Interview Mindset →](./04-interview-mindset/README.md)
- **API (Application Programming Interface)**: A set of rules and protocols that allows different software applications to communicate with each other. [See APIs →](./09-backend/README.md)
- **Asynchronous**: Operations that do not block the execution thread, allowing other tasks to run while waiting for an operation to complete.

## B
- **Backtracking**: An algorithmic technique for solving problems recursively by trying to build a solution incrementally. [See Software Engineering →](./07-software-engineering/algorithms.md)
- **Big O Notation**: Mathematical notation used to describe the limiting behavior of a function, typically to classify algorithms by how they respond to changes in input size (Time/Space Complexity). [See Software Engineering →](./07-software-engineering/big-o.md)
- **Blue-Green Deployment**: A release strategy that reduces downtime by running two identical production environments. [See DevOps →](./15-devops/cicd.md)

## C
- **Caching**: Storing copies of data in a temporary storage location so they can be accessed more quickly. [See System Design →](./13-system-design/building-blocks.md)
- **CAP Theorem**: States that a distributed data store can only simultaneously provide two of the three guarantees: Consistency, Availability, and Partition Tolerance. [See System Design →](./13-system-design/fundamentals.md)
- **CI/CD (Continuous Integration / Continuous Deployment)**: Practices that automate the building, testing, and deployment of applications. [See DevOps →](./15-devops/cicd.md)
- **Concurrency**: The ability of different parts or units of a program, algorithm, or problem to be executed out-of-order or in partial order, without affecting the final outcome.

## D
- **Denormalization**: The process of adding redundant data to a database to improve read performance. [See Databases →](./11-databases/database-design.md)
- **Dynamic Programming (DP)**: An algorithmic technique for solving an optimization problem by breaking it down into simpler subproblems. [See Software Engineering →](./07-software-engineering/algorithms.md)
