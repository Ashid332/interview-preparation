# 60-Day Interview Preparation Plan

The 8-week plan is the sweet spot for most engineers. It allows enough time to deeply understand patterns without burning out. 

## Timeline 

| Week | Focus Area | Key Deliverables |
|---|---|---|
| **Week 1** | Arrays, Strings, Hash Maps | Master Sliding Window, Two Pointers |
| **Week 2** | Linked Lists, Stacks, Queues | Cycle detection, monotonic stacks |
| **Week 3** | Trees, Tries, Heaps | Tree traversals, Top-K problems |
| **Week 4** | Graphs, Backtracking | BFS/DFS, Shortest path, Combinations |
| **Week 5** | Dynamic Programming, Greedy | Memoization, Tabulation, 1D/2D DP |
| **Week 6** | System Design: Fundamentals | Caching, Load Balancing, DB scaling |
| **Week 7** | System Design: Applications | Design Twitter, Uber, Web Crawler |
| **Week 8** | Behavioral, OOD, Mocks | STAR stories, Design Patterns, Full Mocks |

## Phase 1: Data Structures and Algorithms (Weeks 1-5)
- **Goal**: Solve ~100-150 problems (mostly Mediums, some Hards).
- **Strategy**: Do not memorize solutions. Focus on recognizing *patterns* (e.g., "This asks for the shortest path in an unweighted grid -> BFS").
- **Weekly Mocks**: Starting Week 3, schedule one 45-minute peer mock interview every weekend.

## Phase 2: System Design (Weeks 6-7)
- **Goal**: Understand how to map requirements to architecture.
- **Action Items**:
  - Read "Designing Data-Intensive Applications" (selected chapters).
  - Watch mock system design interviews on YouTube.
  - Create standard templates for capacity estimation and API design.

## Phase 3: Final Polish (Week 8)
- **Behavioral**: Document 5-6 versatile stories that cover: Conflict, Failure, Leadership, and Innovation.
- **OOD**: Review SOLID principles and practice designing a Parking Lot or Elevator System.
- **Simulations**: Do full 4-5 hour interview loops with friends or on a platform like Pramp.
