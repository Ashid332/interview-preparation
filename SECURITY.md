# Security Policy

## Supported Versions

The Engineering Interview Handbook is a documentation repository, so versioning primarily refers to the content's accuracy regarding current interview practices.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability (e.g., exposed credentials in a code example, or a malicious external link), please DO NOT open a public issue.

Instead, please email the maintainers directly or use GitHub's private vulnerability reporting feature. We will respond within 48 hours.

**DO NOT** submit a pull request fixing the vulnerability before it has been triaged by the maintainers.
