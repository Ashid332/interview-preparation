# Roadmap

This document outlines the future vision and planned milestones for the Engineering Interview Handbook.

## Phase 1: Repository Stabilization (Current)
- Complete comprehensive V1 content generation.
- Implement robust CI/CD (markdown link checking, linting).
- Establish community governance, code of conduct, and contributing guidelines.

## Phase 2: Community Scaling (Next 6 Months)
- Launch GitHub Discussions for Mock Interview pairing and Resume Roasts.
- Implement "Community Challenges" for solving specific system design problems.
- Gather 100+ verified Interview Experiences from contributors.

## Phase 3: Platform Evolution (12-18 Months)
- Migrate the Markdown repository to a static site generator (e.g., Next.js / Docusaurus) for improved navigation and mobile experience.
- Implement Algolia search for instant topic discovery.
- Create an interactive "AI Interviewer" web application powered by the prompts in our `28-ai-interview-coach` directory.

## Phase 4: Long-Term Vision (2+ Years)
- Expand into specialized tracks (e.g., Hardware Engineering, Product Management).
- Partner with hiring platforms and bootcamps to provide standard evaluation metrics based on our `27-interview-scorecards`.
