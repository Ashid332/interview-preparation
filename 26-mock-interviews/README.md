# Mock Interviews

This module contains a collection of mock interviews for various engineering roles and interview formats. These mock interviews are designed to simulate realistic interview scenarios, complete with setup, transcripts, feedback, and hiring manager notes.

## Available Mock Interviews

* [Software Engineer Mock Interview](software-engineer.md)
* [Frontend Engineer Mock Interview](frontend-engineer.md)
* [System Design Mock Interview](system-design.md)
* [Behavioral Mock Interview](behavioral.md)
* [AI Engineer Mock Interview](ai-engineer.md)

## How to Use This Module

* **Read the transcripts:** Understand the flow of a typical interview.
* **Analyze the feedback:** See how interviewers evaluate candidates.
* **Practice the questions:** Try to answer the questions yourself before looking at the provided answers or improved solutions.
