# Anthropic Interview Experience

## Role/Level
- **Title:** Software Engineer (Infrastructure)
- **Level:** Senior
- **Location:** San Francisco, CA

## Application
- **Method:** Applied directly with a cover letter emphasizing AI safety.
- **Timeline:** Applied Aug 10, completed Sept 15.

## Online Assessment
- **Format:** Take-home assignment (Build a small, secure web service with specific constraints).
- **Outcome:** Passed code review.

## Phone Screen
- **Duration:** 1 hour
- **Topics:** Discussing the take-home assignment, explaining design choices, and modifying the code live.

## Onsite
| Round | Type | Description |
|-------|------|-------------|
| 1 | System Design | Design a highly available logging and monitoring system for inference servers. |
| 2 | Pair Programming | Implementing a complex rate-limiting algorithm with strict correctness requirements. |
| 3 | Safety & Alignment | Deep discussion on AI ethics, misuse vectors, and robust engineering practices. |
| 4 | Behavioral | Standard behavioral with the hiring manager. |

## Offer Details
- **Base:** $210,000
- **Equity:** Standard startup equity package.
- **Sign-on:** $25,000

## Lessons Learned
- The emphasis on writing tests during the interview was refreshing. They actually wanted to see test-driven development.
- The alignment round was very philosophical and required serious thought beforehand.

- Anthropic's blog posts on Constitutional AI.
- Reliability engineering textbooks.
