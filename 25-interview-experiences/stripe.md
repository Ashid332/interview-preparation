# Stripe Interview Experience

## Role/Level
- **Title:** Software Engineer
- **Level:** L2
- **Location:** Remote

## Application
- **Method:** Cold applied online.
- **Timeline:** Applied Feb 1, First round Feb 20.

## Online Assessment
- **Duration:** 1 hour
- **Format:** HackerRank. Implement a basic string parsing utility based on specific rules.
- **Outcome:** Passed.

## Phone Screen
- **Duration:** 1 hour
- **Topics:** "Bug Bash". Given a small open-source codebase, had to find and fix 3 failing test cases.

## Onsite
| Round | Type | Description |
|-------|------|-------------|
| 1 | Integration | Read a public API documentation and build a tool to fetch and aggregate data. |
| 2 | Bug Bash | More complex debugging session in a larger codebase. |
| 3 | System Design | Design a rate-limiting and billing system. Focus on idempotency. |
| 4 | Behavioral | Chat with Engineering Manager about past projects and teamwork. |

## Offer Details
- **Base:** $160,000
- **Equity:** $280,000 over 4 years
- **Bonus:** 10%
- **Sign-on:** $20,000

## Lessons Learned
- Using my own IDE (VS Code) and being able to Google documentation made the interview feel very natural.
- They care deeply about code readability and how you interact while pair programming.
