# Microsoft Interview Experience

## Role/Level
- **Title:** Senior Software Engineer
- **Level:** 63
- **Location:** Redmond, WA

## Application
- **Method:** Applied directly on career site.
- **Timeline:** Applied May 10, First contact June 2.

## Online Assessment
- **Duration:** 60 minutes
- **Format:** Codility test (3 questions, Easy-Medium).
- **Outcome:** Passed all test cases.

## Phone Screen
- **Duration:** 45 minutes
- **Topics:** Discussion of resume, followed by an easy string manipulation question.

## Onsite
| Round | Type | Description |
|-------|------|-------------|
| 1 | Coding | Linked list manipulation and cycle detection. |
| 2 | System Design | Design a distributed cache (similar to Redis). |
| 3 | Behavioral/Coding | Deep dive into a past failure + Tree traversal problem. |
| 4 | As-Appropriate | Meeting with Hiring Manager. Mostly behavioral and product sense. |

## Offer Details
- **Base:** $170,000
- **Equity:** $120,000 over 4 years
- **Bonus:** 20% target
- **Sign-on:** $20,000

## Lessons Learned
- Interviewers were very friendly and collaborative. It felt like pair programming.
- They cared a lot about clean code and naming variables correctly.
