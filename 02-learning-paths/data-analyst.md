# Data Analyst Interview Learning Path

## Role Overview
Data Analysts focus on extracting actionable insights from data, building dashboards, defining business metrics, and communicating findings to stakeholders. This role requires exceptional SQL skills, proficiency in BI tools, and strong business acumen. This 8-week path prepares you for core analytics roles.

## Prerequisites

| Skill Area | Expected Proficiency Level | Resources for Review |
|------------|----------------------------|----------------------|
| SQL | Intermediate | SQLZoo, Mode Analytics |
| Spreadsheets | Advanced (Excel/Google Sheets) | Excel documentation |
| Basic Math | Intermediate (Averages, Medians, Variance) | Basic Stats refresher |

## Weekly Roadmap

### Weeks 1-3: SQL Mastery
SQL is the most critical skill for a Data Analyst.

| Week | Focus Area | Key Concepts | Practice Goal |
|------|------------|--------------|---------------|
| 1 | SQL Foundations | SELECT, WHERE, GROUP BY, HAVING, basic JOINs | 20 Easy/Medium SQL problems on StrataScratch |
| 2 | Intermediate SQL | Subqueries, CTEs (WITH clause), CASE statements | 20 Medium SQL problems |
| 3 | Advanced SQL | Window Functions (ROW_NUMBER, RANK, LEAD, LAG) | 15 Medium/Hard SQL problems |

### Weeks 4-5: Data Visualization & BI Tools
Communicating data visually.

| Week | Focus Area | Key Concepts | Practice Goal |
|------|------------|--------------|---------------|
| 4 | BI Tool Basics | Tableau / PowerBI / Looker basics, connecting data sources | Build a basic dashboard with public data |
| 5 | Dashboard Design | Data storytelling, choosing the right charts, visual hierarchy | Redesign a cluttered dashboard into a clean, executive summary |

### Weeks 6-7: Product Sense & Business Metrics
Connecting data to business outcomes.

| Week | Focus Area | Key Concepts | Action Item |
|------|------------|--------------|-------------|
| 6 | Core Business Metrics | DAU/MAU, Churn Rate, LTV, CAC, Conversion Funnels | Define the top 3 KPIs for a hypothetical e-commerce store |
| 7 | Root Cause Analysis | Investigating metric drops, segmenting data to find anomalies | Framework practice: "Why did user engagement drop 10%?" |

### Week 8: Behavioral & Case Studies
Bringing it all together for the interview.

| Week | Focus Area | Key Concepts | Action Item |
|------|------------|--------------|-------------|
| 8 | Behavioral (STAR) & Mock Cases | Stakeholder management, dealing with messy data | Draft 5 STAR stories, conduct 2 mock interviews |

## Milestones & Checkpoints

- [ ] **End of Week 3:** Can write a query using CTEs and Window Functions without syntax errors.
- [ ] **End of Week 5:** Can take a raw dataset and turn it into a clear, interactive dashboard.
- [ ] **End of Week 7:** Can confidently answer open-ended business questions using a structured framework.
- [ ] **End of Week 8:** Able to communicate technical findings to a non-technical mock interviewer.

## Company Recommendations

- **SaaS/Tech Startups:** Heavy focus on product metrics, conversion funnels, and self-serve BI tools.
- **E-commerce / Retail:** Focus on inventory metrics, LTV/CAC, cohort analysis, and seasonal trends.
- **Agencies / Consulting:** Focus on client communication, rapid dashboard generation, and Excel mastery.

## Interview Readiness Checklist

- [ ] Solid grasp of different types of SQL JOINs (Inner, Left, Right, Full).
- [ ] Can explain the difference between RANK(), DENSE_RANK(), and ROW_NUMBER().
- [ ] Prepared a portfolio of 1-2 polished dashboards.
- [ ] Comfortable discussing times you pushed back on a stakeholder's request for data.
