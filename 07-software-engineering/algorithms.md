# Algorithms

## Overview
Algorithms are step-by-step procedures for solving problems. Key topics include sorting, searching, recursion, dynamic programming, greedy algorithms, and graph traversal. They go hand-in-hand with data structures to create efficient solutions.

## Interview Questions
* **Difficulty:** Hard
* **Frequency:** Very High
* **Companies:** Google, Meta, Amazon, Apple, Netflix.

### Excellent Answer
"I approach algorithmic problems by first identifying the core pattern. If it involves finding the optimal substructure, I consider dynamic programming. I always start with a brute-force approach to ensure correctness before optimizing for time and space."

### Common Mistakes
* Memorizing solutions instead of understanding the underlying patterns.
* Struggling with recursive call stacks and base cases.
* Failing to optimize a brute-force solution.

## Real-World Applications
* **Sorting Algorithms:** Displaying search results, e-commerce product listings.
* **Dynamic Programming:** Sequence alignment in bioinformatics, inventory optimization.
* **Graph Algorithms:** Network routing, recommendation systems.
